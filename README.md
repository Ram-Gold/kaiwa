# KAIwa 🇯🇵

A fully local, privacy-first Japanese learning tutor — like Pingo, but powered by LocalAI running entirely on your machine.

## Features
- **JLPT Reviewer** — practice questions and progress tracking, starting at N5
- **AI Kaiwa (会話)** — real-time conversational practice with a local LLM, no cloud calls
- **Persistent Memory** — remembers who you are, your current skill level, and your N5 score across sessions
- **100% Local** — powered by LocalAI, no data leaves your machine
